# r-todo

یک برنامه ساده‌ی مدیریت وظیفه در Rust که از طریق خط فرمان کار می‌کند.

## ویژگی‌ها

- افزودن وظیفه جدید
- حذف وظیفه
- تغییر وضعیت انجام‌شدن یک وظیفه
- نمایش لیست همه‌ی وظایف
- پاک‌سازی تمام وظایف ذخیره‌شده
- ذخیره‌سازی دائمی در مسیر داده‌های محلی برنامه

## پیش‌نیازها

- Rust 1.80+ (یا هر نسخه‌ی پایدار جدیدتر)
- Cargo

## نصب

```bash
git clone https://github.com/alix1383/r-todo.git
cd r-todo
cargo build --release
```

## استفاده

برای اجرای برنامه از دستورات زیر استفاده کنید:

```bash
cargo run -- add "نوشتن README پروژه"
cargo run -- list
cargo run -- toggle "نوشتن README پروژه"
cargo run -- remove "نوشتن README پروژه"
cargo run -- reset
```

همچنین می‌توانید فایل buildشده را مستقیماً اجرا کنید:

```bash
./target/release/r-todo add "خرید مواد غذایی"
```

## دستورات

- `add <task_name>`: افزودن یک وظیفه جدید
- `remove <task_name>`: حذف یک وظیفه بر اساس نام
- `toggle <task_name>`: تغییر وضعیت انجام‌شدن یک وظیفه
- `list`: نمایش تمام وظایف
- `reset`: حذف همه‌ی وظایف ذخیره‌شده

## ذخیره‌سازی داده‌ها

وظایف در مسیر داده‌های محلی سیستم عامل با استفاده از کتابخانه‌ی `directories` ذخیره می‌شوند. اگر فایل داده وجود نداشته باشد، برنامه به صورت خودکار هنگام اجرا آن را ایجاد می‌کند.

## ساختار پروژه

```text
r-todo/
├── Cargo.toml
├── crates/
│   ├── cli/
│   │   └── src/
│   └── database/
│       └── src/
└── src/
    └── main.rs
```
